## ⑤工夫した点・こだわった点

- htmlではじめに骨子を作って全体ボリュームを把握した。

- BEMという書き方があると知り、できる範囲で意識して書いた。
- 学習の仕方として、codexに仕様書を投げてhtmlとcssを作ってもらい、完成イメージを掴んだ。

## ⑥難しかった点・次回トライしたいこと(又は機能)
- htmlで一旦骨子を作るまではよかったが、class名をほぼつけていないままcssをいじり始めたため、class名を途中で追加するたびにデザインが崩れる状況になって修正に追われた。初心者のうちはなるべく名前をつけておくようにしたい。
- margin、paddingの細かな設定に苦戦。
- 送信フォーム作りでもうまくつくれずに苦戦。
- AIは志望動機の部分を<fieldset>と<legend>を作るよう提示してきたが罫線がずれて修正できず、<div>で普通に作って回避した。
- 仕様書にコメントのあったスライドショーやレスポンシブ対応までできなかったので、次回チャレンジしてみたい。
